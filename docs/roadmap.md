# Roadmap

主线:从「看得见」到「看得懂、查得到」。每版一个主题,版本号随主题定,不按时间排期。

## v0.3.0 — 复盘与减噪(纯客户端,无上游依赖)

跑完之后的卡片几乎是死数据,长会话里还占地方。这一版让 run 卡片「收得起、看得懂」:

1. **完成态折叠**:run 结束后默认收成一行摘要(3 阶段 · 5/5 完成 · 2 次 loop · 4m12s),点击展开完整时间线。跑完的卡片不该比跑着的还吵。
2. **耗时与次数指标**:每 agent 耗时、每阶段耗时、loop 实际执行次数,从已有 turn 数据推导,不依赖新上游事件。
3. **失败/中断复盘**:失败站与中断点的高亮摘要(哪个站、断在哪个 agent),替代现在只在顶部一行小字。
4. **测试补强**:script-scan 与 timeline-model 的边界用例(空 phases、孤节点、双向边、超深 loop 链),render 路径保持 smoke。

## v0.4.0 — 反向导航与多 run 总览(先探上游,可降级)

1. **子代理侧返回锚点**:跳进子会话后能看到「← 属于 workflow X」并跳回。先探 0.2.1 是否有可注入的子会话槽位;没有就降级为父卡片列出全部子代理跳转入口(已具备),并把「从子返回」记为 blocked。
2. **会话内 run 索引**:一个会话多次 workflow 调用时,卡片顶部给一条迷你索引(第几次、状态),点击滚动定位。
3. **跳转记忆**:从子会话返回时,父卡片保持展开/滚动位置,不重置。

## v0.5.x — 分发与本地化

1. **npm publish**:安装从 GitHub clone 简化为一条命令;继续受 pnpm supply-chain 策略影响,先备好 publish 流程。
2. **locale channel**:卡片文案(「工作流运行中」「子代理」等)跟随 DSH 语言设置,不再硬编码中文。
3. **兼容性跟进**:DSH 0.3.0-rc 一出就跑兼容矩阵(现已声明 `<0.3.0`,到期前必须重新验证或放宽)。

## 插队规则

**live per-agent output**(卡片里直接流式显示子代理输出)仍是价值最高的一项,继续 blocked on 上游事件暴露;一旦 0.2.x/0.3.x 放出对应事件,立即插队为下一版主题,以上全部顺延。

## 明确不做

- 替换官方 workflow 执行逻辑(纯展示层,执行永远归官方工具)
- 跨会话的 run 历史持久化(涉及存储方案与隐私边界,收益存疑)
- 非 web 平台适配(当前只声明 web profile)
